# Автошкола «Светофор» — тренажёр ПДД

**Открыть тренажёр:** https://bigmax178-alt.github.io/pdd-trainer/

Тренажёр теоретического экзамена ГИБДД. В ГИБДД два комплекта билетов, и тренажёр устроен так же:

- **ABM** — одни и те же билеты для категорий **A, B, M** и подкатегорий **A1, B1**;
- **CD** — одни и те же билеты для категорий **C, D** и подкатегорий **C1, D1**.

Если сдаёте сразу на A и B, учить нужно один комплект. Для BE, CE, C1E, DE, D1E, Tm и Tb теория тоже обязательна, но комплект билетов для них в открытых правилах не указан — его стоит уточнить в автошколе.

## Возможности

- **Билеты** — решение подряд, статус каждого билета.
- **Экзамен по правилам ГИБДД** — 20 вопросов, 4 блока, 20 минут; ошибка → +5 вопросов той же тематики и +5 минут; все условия провала.
- **Темы**, **марафон**, **работа над ошибками**, **избранное**, **сложные вопросы**, **поиск**.
- **Вероятность сдачи экзамена** — точный расчёт по правилам экзамена.
- **Умная тренировка** (адаптивная подборка) и **интервальное повторение** (Лейтнер).
- **Дневная цель, серия дней, статистика**, история экзаменов.
- **Справочник знаков** (векторные SVG), тёмная тема, горячие клавиши, экспорт/импорт прогресса.
- **REST API**: аккаунты, синхронизация прогресса без потерь, серверный экзамен с анти-читом.

## Быстрый старт

Нужен Node.js ≥ 22.18 (TypeScript запускается напрямую, без сборки).

```bash
npm install
```

```bash
npm run dev
```

Откроется веб-клиент на http://localhost:5173. Готовый самодостаточный файл — `dist/index.html` (`npm run build`), его можно просто открыть в браузере.

```bash
npm run start:api
```

API на http://localhost:8080 (см. [docs/API.md](docs/API.md)).

```bash
npm run check
```

Проверка типов, валидация контента, все тесты и сборка — то же, что на CI.

## Учётные записи

Вход в тренажёр — по приглашению. Сервер, база данных и платные сервисы не нужны: всё работает на GitHub Pages.

| Роль | Может |
|---|---|
| **Администратор** | создавать управляющих и учеников |
| **Управляющий** | создавать учеников |
| **Ученик** | заниматься в тренажёре |

Как это устроено:
- Учётная запись — ссылка-приглашение с электронной подписью (ECDSA P-256). Сайт проверяет подпись открытым ключом
  автошколы из `school/school.json`; подделать приглашение без закрытого ключа невозможно.
- Ученик открывает ссылку один раз — и он в системе. На другом устройстве — та же ссылка.
- Сотрудник при первом входе придумывает пароль: им на устройстве шифруется ключ для выдачи доступов (PBKDF2 + AES-GCM).
- У приглашения есть срок; доступ ученика не может пережить доступ управляющего, который его выдал.
- Заблокировать доступ: добавить его ID (виден в журнале «Управление») в список `revoked` файла `school/school.json`.
  Блокировка управляющего закрывает и выданных им учеников.
- Журнал выданных доступов и прогресс ученика хранятся на устройстве (центральной базы нет).

Первичная настройка (один раз; ссылка администратора пишется в файл вне репозитория и на экран не выводится):

```bash
node scripts/school-init.ts --site https://bigmax178-alt.github.io/pdd-trainer/ --out "../Светофор — ключ администратора.txt"
```

Без `school/school.json` (например, при открытии `dist/index.html` как файла) тренажёр открыт всем.

## Официальные билеты

Сайт работает на официальных билетах ГИБДД: по 40 билетов ABM и CD (1516 вопросов) с оригинальными картинками,
пояснениями и справочником знаков. Источник — открытый набор [etspring/pdd_russia](https://github.com/etspring/pdd_russia),
снимок зафиксирован в `scripts/official-source.ts` (версия 2026.q3.0). Картинки в репозиторий не коммитятся:
их скачивает и проверяет сборка.

```bash
npm run fetch:official
```

После этого `npm run build` и `npm run dev` используют официальные билеты. Без них приложение работает на встроенном демо-банке
(3 билета ABM, 2 билета CD), например если открыть `dist/index.html` как локальный файл.
